# 验证范围

公共代码的回归测试只使用临时数据、模拟对象和合成波形，不读取维护者的实验目录。

通用版已在不包含 project_config.local.json、真实数据及历史输出的代码副本中验证：

- 无私人配置时只加载 DEMO，测试不依赖维护者的实验名称。
- 40 项单元/回归测试通过，覆盖条件配置、输入单位、防重复缩放、峰位对齐、坏段合并、事件切分及文件回读等。
- 合成 ECG/EDA 完成预处理、QC、网页保存和审核 FIF 导出；最终阶段执行并生成处理报告。
- 合成输入及结果生成后，Git 候选文件检查仍不包含数据或私人配置。

本机验证环境：Python 3.11.4，MNE 1.7.0，NeuroKit2 0.2.12，NumPy 1.24.4，SciPy 1.14.1，pandas 2.0.3，Matplotlib 3.7.2，Plotly Python 7.1.0，Streamlit 1.64.0。浏览器离线 Plotly.js 为单独的捆绑版本，保留原许可。

验证使用同一已安装依赖环境中的干净代码副本，不等于每个操作系统或依赖版本都经过重新安装测试。requirements.txt 未锁定所有间接依赖；自己的正式研究应记录实际依赖版本并冻结分析环境。

这属于工程验证，不是峰检测准确率、人群适用性或科研阈值的验证。模拟数据可通过或被 QC 排除，状态不应为了演示而隐藏。实际数据仍需人工复核。
